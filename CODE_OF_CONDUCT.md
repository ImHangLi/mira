# Code of Conduct

Mira follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be kind and patient.
- Assume good intent, and give feedback about the work, not the person.
- No harassment, insults, or personal attacks.

This applies in issues, pull requests, discussions, and every other project space.

To report a problem, write to hang.dev@outlook.com. Reports are private. The maintainer reads each report and can warn, or remove, a person who does not follow these rules.
